   Commit to main, ardından Push origin.
4. GitHub > Actions > DeporiaQ Windows Release > Run workflow
   Branch: main / version: 0.22.5. Bir kez çalıştırın.
5. Akış önce Qt arka plan testini, ardından EXE/kurulum derlemesini ve Windows testini yapar.
   Windows testi, 0.22.4 güncelleyicisini derleyip kurulumun onu kapattığı durumu tekrarlar.

   Test 180 saniye içinde açılan ve açık kalan pencereyi göremezse yayın durur.
6. Kırmızı sonuç çıkarsa tekrar sürüm yayımlamayın. DeporiaQ-0.22.5-test-results
   artifact dosyasındaki günlükleri paylaşın. Yeni manifest henüz yayımlanmaz.
7. Yeşil Success: Releases > 0.22.5 altında Setup EXE ve manifesti kontrol edin.
8. Kurulu 0.22.4 içinden güncellemeyi başlatın. Kurulumdan sonra giriş ekranı açılmalı.
   Giriş yapıp 0.22.5 yazısını ve depo arka planını kontrol edin.
